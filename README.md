# 🎮 AllGamesIntoTG — Telegram-бот каталога игр

Публичный Telegram-бот для каталога игр: поиск по базе, новости, подборки и раздача файлов. Файлы загружает только администратор, остальные пользователи могут искать и скачивать.

## Возможности

- 🔍 **Поиск игр** по названию, жанру, платформе (с пагинацией)
- 🎮 **Каталог** — все игры с карточками, обложками, описанием и ссылками
- 📰 **Новости** — анонсы и новости игрового мира, публикуются админом
- 📁 **Подборки** — тематические коллекции игр
- 📥 **Скачивание файлов** — файлы игр загружает только админ, пользователи скачивают кнопкой
- 🔐 **Админ-панель** — управление играми, новостями, подборками, рассылка пользователям
- 💾 Хранение в JSON-файлах (data/), без БД — просто и портативно

## Требования

- Node.js 18+
- Токен бота от [@BotFather](https://t.me/BotFather)

## Быстрый старт

```bash
npm install

# Настройте .env (см. .env.example):
#   BOT_TOKEN=...
#   ADMIN_IDS=123456789
#   BOT_USERNAME=@AllGamesIntoTG
#   RAWG_API_KEY=   # опционально, внешний поиск

npm start        # или npm run dev (авто-перезапуск)
```

## Команды

| Команда | Описание |
|---|---|
| `/start` | Главное меню |
| `/help` | Помощь |
| `/search` | Поиск игры по названию/жанру/платформе |
| `/news` | Последние новости |
| `/collections` | Подборки игр |
| `/latest` | Последние добавленные игры |
| `/games` | Все игры |
| `/admin` | Панель администратора (только для админа) |
| `/broadcast <текст>` | Рассылка всем пользователям (админ) |

## Как добавить игру (админ)

1. `/admin` → «➕ Добавить игру»
2. Укажите название, описание, жанры, платформы, ссылку, обложку
3. Отправьте **файл игры** (zip/rar/7z/exe) — сохранится в Telegram и станет доступен для скачивания

Пользователи увидят карточку игры с кнопкой **«📥 Скачать»**.

## Деплой

### На Render (рекомендуется, бесплатный тариф)

Проект уже настроен под Render: в `render.yaml` лежит Blueprint, `src/index.js` поднимает HTTP-сервер с health-check (`/` → «AllGamesIntoTG bot is running») и работает в long-polling режиме (как quran-ai-bot).

1. Залейте репозиторий на GitHub (уже сделано: `mamadjonovali2012-blip/all-games-into-tg-bot`)
2. На [render.com](https://render.com) → **New +** → **Blueprint** → выберите репозиторий — Render сам прочитает `render.yaml`
3. Задайте секреты: в `BOT_TOKEN` впишите токен бота (поля `sync: false`)
4. Deploy — бот поднимется за 1–2 минуты и сразу заработает

**Автодеплой:** в `render.yaml` стоит `autoDeploy: true` и `buildCommand: npm ci` — каждый пуш в GitHub автоматически пересобирает и перезапускает бота, установка зависимостей идёт быстро (npm ci).

### Чтобы бот не «засыпал» (аптайм)

На бесплатном тарифе Render «усыпляет» сервис после ~15 минут без трафика — long polling останавливается, бот молчит. Решение — внешний пинг каждые 10 минут (бесплатно, без прав GitHub):

1. Зарегистрируйтесь на [cron-job.org](https://cron-job.org) (или используйте UptimeRobot)
2. Создайте задачу: **URL** = URL вашего сервиса (например `https://all-games-into-tg-bot.onrender.com`), **интервал** = 10 минут
3. Cron-job будет дёргать health-эндпоинт — Render считает сервис активным и не усыпляет

Бот отвечает на `GET /` текстом «AllGamesIntoTG bot is running» — пингер будет видеть, что всё живо (200 OK).

### Обычный сервер / VPS

```bash
npm ci
npm start   # long-polling, без вебхука
```

Для продакшена — `pm2 start src/index.js` или systemd.
